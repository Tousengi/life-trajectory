## 修改页面

源码在 `src/page.html`。改完运行：

```
python3 build.py
```

它会把 `src/` 里的地图数据和依赖库合进 `index.html`。

## 数据来源与许可

- 国界轮廓：[world-atlas](https://github.com/topojson/world-atlas)，Natural Earth 1:50m / 1:110m（公有领域）
- [d3-geo](https://github.com/d3/d3-geo)、[d3-array](https://github.com/d3/d3-array)（ISC）、[topojson-client](https://github.com/topojson/topojson-client)（ISC）
